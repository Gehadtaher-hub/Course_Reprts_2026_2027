PUBLIC COURSE RESULTS PORTAL

Extracted course catalog:
- Computer Science program: 65 courses
- Information Systems program: 62 courses

LEVEL ASSUMPTION
The Excel files do not contain a separate level column. Level was derived from the first digit in the course code: 1=Level 1, 2=Level 2, 3=Level 3, 4=Level 4. Review course_catalog.xlsx before publishing.

PDF PATHS
For every course, upload the two files using this pattern:
pdfs/computer-science/CSD101/course-results.pdf
pdfs/computer-science/CSD101/course-survey.pdf
pdfs/information-systems/ISD101/course-results.pdf
pdfs/information-systems/ISD101/course-survey.pdf

GitHub will create folders when you upload a path or you can add them locally before upload. File and folder names are case-sensitive in GitHub Pages.

PRIVACY
This portal has no login. Only publish aggregated results and survey summaries. Do not publish student names, IDs, individual grades, or identifiable survey responses.
